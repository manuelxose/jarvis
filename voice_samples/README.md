# Instrucciones para grabar tu voz

Para una buena clonacion necesitas:
- Minimo 5 archivos WAV de 30-60 segundos cada uno
- Formato: WAV, 22050 Hz, mono, 16-bit
- Entorno silencioso (sin eco, sin ruido de fondo)
- Voz natural, no forzada

Puedes grabar con Audacity (gratuito):
1. Descarga Audacity
2. Configura: 22050 Hz, Mono
3. Graba textos variados (noticias, libros, conversacion normal)
4. Exporta como WAV
5. Guarda aqui como: sample1.wav, sample2.wav, ...

Cuantos mas audios y mas variados, mejor calidad de clonacion.
